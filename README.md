## Wat is deze Website
Deze website informeert mensen over wat ik afgelopen zomer heb gedaan en waar ik de zomer heb doorbracht. Je kan ook foto's zien van de plekken waar ik ben geweest of waar ik mijn zomer heb doorbracht.
## Waarvoor dient deze website?
Deze website dient om me zelf voor te stellen aan mensen die geïntreseerd zijn om mij te leren kennen. Ik heb deze website gemaakt zodat ik niet elke keer mijn woorden moet herhalen maar zodat mensen snel kunnen zien wie ik ben en wat ik afgelopen zomer heb gedaan.
## Welke technologieën heb ik gebruikt?
Ik heb HTML gebruikt om alle zinnen te schrijven. Ik heb ook CSS gebruikt om de HTML code leesbaarder te kunnen maken voor mensen die niet veel kennis hebben van HTML of CSS. Ik heb Git push gebruikt om de Code naar GitHub te sturen, want dit kost me minder tijd dan dit manueel te doen.
## Welke functies heb ik gebruikt?
Ik heb vooral bootstrap gebruikt om de lay-out de maken van deze website omdat ik na 2 maanden al zo goed als alles ben vergeten over HTML en CSS.
## Hoe kan iemand mijn website bekijken?
Je kan mijn website bekijken door deze File te downloaden en dan openen in VSCode.
## Wie heeft de website gemaakt?
Ik ben Ahmad en ik heb deze website gemaakt. Als je meer info wilt over mij dan zou ik deze website gaan bekijken.
